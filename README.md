# 🏅 Mike: E-commerce de Deportes Terrestres y Acuáticos

¡Bienvenidos a **Mike**! Este proyecto es el resultado de un intenso trabajo colaborativo desarrollado durante el **Hackathon de Generation México**. Nuestra plataforma busca conectar a entusiastas del deporte con el equipo de mejor calidad, dividiendo la experiencia en dos grandes mundos: **Tierra** y **Agua**.

---

## 🚀 Sobre el Proyecto
Mike no es solo una tienda, es una experiencia diseñada para deportistas. El objetivo principal fue crear una plataforma escalable, robusta y con una interfaz de usuario fluida (UX/UI) utilizando tecnologías de vanguardia como **HTML, Java, CSS y Bootstrap**.

### 🌟 Características Principales
* **Catálogo Dinámico:** Filtrado inteligente entre deportes acuáticos (surf, natación, buceo) y terrestres (fútbol, running, senderismo).
* **Diseño Responsivo:** Carruseles personalizados y cards interactivas que se adaptan a cualquier dispositivo.
* **Arquitectura Robusta:** Implementación de lógica de negocio en el backend con manejo eficiente de datos mediante Colecciones (Maps y Sets).
